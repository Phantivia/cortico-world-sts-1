# Third-party components

Slay the Spire is owned by Mega Crit. Game files and assets are supplied by the
operator and are not distributed in this package.

ModTheSpire and BaseMod are separately installed runtime/build dependencies:

- https://github.com/kiooeht/ModTheSpire
- https://github.com/daviscook477/BaseMod

CommunicationMod is compiled from revision
`5e417eb189530986b9047a3c9426889fb261d146` of
https://github.com/ForgottenArbiter/CommunicationMod. Its MIT license is included
in the generated CommunicationMod JAR. No upstream source or binary is embedded
in the extension package.

`mod/resources/cursor-companion.json` comes from the MIT-licensed
cortico-world-pvz cursor companion. The rendering code in this package uses that
palette, sprite, and animation data.

https://github.com/Phantivia/cortico-world-pvz
